# Forerunner 165

2024年2月に買った。それ以前は Fitbit Inspire HR を使っていたのだけど、もうちょっと真面目に走ろうと思ったのと、Google に買収された後の Fitbit の将来が不安だったのもあって、乗り換えた。

この不安はすでにあたりつつあり、Fitbit の体重計の Aria では、[ゲストの体重を編集する機能が一年近くこわれている](https://community.fitbit.com/t5/Aria-Scales/Aria-2-won-t-register-guest-weight/m-p/5396164)。体重計側では「ゲスト」として体重を送信しているっぽいのだけど、Web やアプリからゲストの体重は表示されないので、結果としてそれを自分の体重として修正する導線がなくなっているのだ。

## ボディバッテリー

2020年に、[ひとでさんのまわりで流行っていた](https://blog.sushi.money/entry/2020/03/07/192506)らしく、当時に読んだのをうっすら覚えている。

> GARMINのBody Batteryを計測できる時計が身の回りで流行っていて、Slackに「いまbody battery70です」とか書いて元気さをアピールしたり、Body Batteryめっちゃ下がってるので難しいことをする気力はないという表明をしたりしていた。

たしかに面白い。ゲームにある HP みたいな感じなのだけど、

- 寝ているときに増えて、あとは一日をかけて減っていくだけ
- 飲酒すると HRV が悪化して、寝ているときの増分がすくなくなる

基本的には回復しないので、世知辛いところもある。
