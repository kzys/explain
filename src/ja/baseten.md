# Baseten

2025年10月から、[Baseten](https://www.baseten.co/) という会社で働いている。本社はサンフランシスコにあって、私も入社直後に一週間だけ出張していた。その後はシアトルからリモートで働いている。

会社は、いわゆる AI スタートアップで、推論のためのインフラ (というと曖昧だけど、基本的には GPU をはじめとする計算資源) を他の企業に提供している。プログラマの人々にわかりやすいところだと、たとえば Zed の入力予測には [Zeta](https://huggingface.co/zed-industries/zeta) という Qwen2.5-Coder-7B をファインチューンしたモデルが使われていて、[Baseten 上のインフラ](https://www.baseten.co/resources/customers/zed-industries-serves-2x-faster-code-completions-with-baseten/) で実行されている。

Baseten 上のインフラといっても、その下の実際の VM は色々なパブリッククラウドに分散している。AI 特需からくる GPU 不足にマルチクラウドで立ち向かうのは、2025年らしさがあって良いなと思う。
