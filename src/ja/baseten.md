# Baseten

2025年10月から、[Baseten](https://www.baseten.co/) という会社で働いている。本社はサンフランシスコにあり、最近になってシアトルにもオフィスができた。コワーキングスペースの一部屋を借りているだけだけど、出勤してみるとなかなか便利で、いまは週に3日くらい通って働いている。

会社は、いわゆる AI スタートアップで、

- オープンウェイトなモデルを OpenAI/Anthoropic 互換の API で使える Model API
- 任意のモデルを動かせる PaaS 的な Dedicated Inference
- ファインチューンや強化学習などの学習のためのプラットフォーム
- 任意のコードを実行するためのサンドボックス

などなどを提供している。

アメリカのスタートアップで働くのは、前職の Fly.io をふくめて2回目、いわゆる PaaS っぽいものを作るのは、さらに前職の AWS をふくめて3回目だけど、毎回ちゃんと学びがあって面白い。今回は GPU と Kubernetes が大きな違いかなと思う。
