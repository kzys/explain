# X (元 Twitter)

* 2007-12 - アカウント作成
* 2025-01 - [Elon Musk の変な敬礼](https://www.reuters.com/world/us/musks-hand-gesture-during-trump-inauguration-festivities-draws-scrutiny-2025-01-21/) を期に休止
* 2025-10 - 転職を期にアカウント再開
* 2026-01 - 過去の投稿を削除

転職したときに、スタートアップ社員たるもの、政治的な色々は一度おいて、つかえるチャンネル全てで会社を推していくべきではないか、と考え直したのだけど、再開後の宣伝投稿もあんまり伸びないし、やっぱり終わりにした。

2025年に止めたときには、福地さんの [SNS から距離を置くことにした](https://fukuchi.org/essay/2025/quit_social_media/) (2025) と同じ気持ちで、

> さて、であるならば、SNS のアカウントなんかはとっとと消してしまえばいいではないか… とは何度も思うのだが、一方で、一度ネットに送り出した情報はできるだけ消さないで残しておくべきである、という昔からの因習が、アカウント削除を躊躇させるんだよね

過去の投稿の削除まではふみこまなかったのだけど、今回はそれも削除してしまったので、本当に終わり。投稿を消すのには [lucahammer/tweetXer](https://github.com/lucahammer/tweetXer) を使った。
