# Medito で瞑想する

[Medito](https://meditofoundation.org/medito-app/) は [Medito Foundation](https://meditofoundation.org/) というオランダの NPO が作っている、フリーの瞑想アプリ。

私は数年前は [Headspace](https://www.headspace.com/) を使っていて、これはアニメーションもかわいくて良かったのだけど、有料会員にはならなかった。

Medito はアニメーションとかはなく音声だけなのだけど、瞑想中って基本的には目も閉じているわけで、日々の瞑想にはこれでも十分かなと思って使っている。2026/06 にちょっとだけ寄付もした。
