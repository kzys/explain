# nerd-snipe する/される

Amazon のころはあまり見かけなかったけど、そのあとの Fly.io とか Baseten で見かけるようになった単語に "nerd-snipe" というのがある。

コンピュータ好き向きの面白い問題、たとえば「ふだんは速い API だけど一日に数回遅くなるときがある」みたいなものを目前に、ほかの色々を中断して「GC のメトリクスってある?」「遅くなる時間って毎日おなじ? ログをアップロードする cron とか無い?」「でもこの API ディスクとかさわらないよねえ...」と、そっちを追いかけてしまうみたいなことをさしていて "I got nerd-sniped" とか　”I was trying to nerd-snipe someone here" といったふうに使う。

もともとは xkcd の [Nerd Sniping](https://xkcd.com/356/) (2007) に由来していて、直訳すると「オタク撃ち」だけど、2ちゃんねる育ちの日本人としては「釣り」っぽい雰囲気があるように思う。そんな餌で俺様が釣られクマー。

古い話をすると、高林さんが、[ハッカー養成塾: 深追い、佳境、バッドノウハウ](http://0xcc.net/pub/osm2006/) (2006) で書いていた「深追い」ともちょっと近い。

> 深追いとは、文字通り、何かについて深く追求することです。筆者の周りのハッカーは、技術的に何か気になる点があると、納得がいくまでとことん深追いします。普通は知らなくていいようなことでも、彼らは詳細まで理解しないと気がすまないようです。知識に対するこような好奇心と執念深さはハッカーを特徴づける気質のひとつではないかと思います。

つまり、nerd-sniping というのは「深追い気質のある人々を釣る」という行為だといえると思う。
