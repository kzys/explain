# ミクシィ

2008年に新卒入社して、2012年まで働いた。

辞めたあとの2013年に[追い出し部屋](https://toyokeizai.net/articles/-/23177?display=b)のことがあったので、完全に「良い会社でした!」という調子でかたるのには無理があるけど、一方で、一番最初の未熟だった私をひろって育ててくれた会社だったとも思う。

私がいまだに、awk と sed を組み合わせるのに限界を感じたときに perl -ne とかできるのはミクシィで Perl を書いていたからで、なので [PSGI/Plack](https://plackperl.org/) 時代の Perl スターたち (宮川さんや Audrey Tang さん、などなど) には先輩感を感じてしまう。
