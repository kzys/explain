# ウクレレを練習している

2025年の10月にウクレレを買った。

そもそも、下の子がギターをやりたいと言い出して、話をよく聞くとバイオリンのような気もしたけど、まずは家にあったエレキギターを渡してみた。しかし、エレキギターは子どもには大きすぎるし、弦も硬くて、全体的にむずかしい。もうちょっと子どもサイズの楽器はということで、ウクレレにたどりついた。

私と下の子ふたりで、[Yousician](https://yousician.com/) を iPad にいれて練習している。

椎名林檎、東京事変、tricot と育ってきた身からすると、エレキギターのかっこよさというのはウクレレでは代替できないけれど、一方で、ウクレレの小さくぱっとはじめられる感じはとても良い。やりなおせるなら、ウクレレで練習してからギターにすすむべきだったなと思う。
