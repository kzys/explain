# Kirkland Signature Men's Stretch Tech Pant

Kirkland は Costco オリジナルのブランドで、巨大なプラスチックラップなどで有名。服まで Kirkland で買うのはさすがにお父さんすぎる気がするけれど、これは気に入っていて、まったく同じものを2つ持っている。

20代のころは常にジーンズを履いていたのだけど、子供がうまれてからは洗濯物が増えたので、ほかの色々と一緒に洗濯機になげこめるようなズボンをさがしている。これもそのひとつ。細身で色々あわせやすく、ジッパー付きのポケットがあって便利。

縫製はところどころ甘くて、糸がはみ出したりしているところがあった。ここらへんは値段相応。
