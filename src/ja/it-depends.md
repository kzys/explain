# 「要はバランス」と "it depends"

[要はバランスおじさんが嫌い](https://wtrclred.io/ja/posts/19) (2026) を読んだ。いくつかの話は、Sarah Cooper の [10 Tricks to Appear Smart in Meetings](https://web.archive.org/web/20150204032239/https://thecooperreview.com/10-tricks-appear-smart-meetings/) (2016) に通じるところがあると思う。"Can we take a step back here?" じゃないんだよ、という。

わたしのまわりで、というのはアメリカのソフトウェア業界の一部で「要はバランス」に位置する言葉は "it depends" だと思う。

何も言っていないに等しく、そのことに人々の間に合意があるので、Slack とかだと "Sorry but it depends" とか "I hate to say this, but it depends" とか、一拍おいて「これがワイルドカードなのはわかってますよ」とするひとが多い。前向きな方向だと、"It depends on ..." と、最初から具体例にふみこんでしまう手もある。素で "It depends" と言い放つのはあんまりおすすめしない。
