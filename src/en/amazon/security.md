# Security, durability, availability, speed

[Colm MacCarthaigh tweeted](https://xcancel.com/colmmacc/status/986286693572493312?lang=en) in 2018:

> Security, durability, availability, speed.
> That's the priority order I think about for design trade-offs and it's never let me down.
> Simplicity and Cost are huge too but more like guiding principles.

I don't think it was Amazon's official policy, but it was reasonable.
