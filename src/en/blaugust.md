# Blaugust

[Blaugust](https://www.containsmoderateperil.com/blog/2026/7/14/blaugust-2026-q-ampa) is a month-long blogging event. While I don't think this site is a "blog", it is open to any form of content creation. I'm going to participate in the event this month.

> It’s month long event to encourage new bloggers and content creators, as well as those who’ve drifted away from existing blogs who are looking for the motivation to resume writing.

Apparently [it has been running since 2014](https://aggronaut.com/2014/07/30/gospel-of-blaugust/), though I only learned about it in 2026 via [its Japanese counterpart](https://www.nejimakiblog.com/entry/blaugust-2026-blog-write-hachigatsu).
