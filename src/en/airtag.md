# AirTag

## Making silent AirTags

There are a lot of videos on YouTube. I followed the video below.

[Why Everyone is BREAKING OPEN APPLE AIRTAGS](https://www.youtube.com/watch?v=gSRc1DScOY8)

As some folks commented on the video, recent AirTags are glued. So opening an AirTag without breaking the tabs is harder. I have opened two AirTags, succesfully removed the speakers, but broken the tabs.

## AirTag-friendly minimal wallets

I use [Thread's vertical wallet](https://www.threadwallets.com/products/black-vertical-wallet). I've attached an AirTag to the wallet's D-ring.

There are wallets that made for AirTag, but I like minimal wallets. I had ones from [Bellroy](https://bellroy.com/) and [Distil](https://distilunion.com/) before.
